# ALI2025 App Development Workflow

## Prerequisites Setup

1. **Install Dependencies**
```bash
npm install
```

2. **Install CocoaPods (iOS)**
```bash
cd ios && pod install && cd ..
```

3. **Start Development Server**
```bash
npx expo start
```

## Development Workflow

### 1. Project Structure Overview
- **app/**: Expo Router file-based routing
  - `(ar)/`: AR functionality with ViroReact
  - `(courses)/`: Course content screens
  - `(modules)/`: Learning modules
  - `(resources)/`: Resource materials
  - `(tabs)/`: Tab navigation screens
  - `(videos)/`: Video content
- **components/**: Reusable UI components
- **assets/**: Images, models, and static files
- **data/**: App data and configurations

### 2. Key Technologies Used
- **Expo Router**: File-based navigation
- **ViroReact**: AR/3D model rendering
- **React Native Vision Camera**: Camera functionality
- **Axios**: HTTP requests
- **AsyncStorage**: Local data persistence
- **Stack Navigation**: Navigation structure

### 3. Development Commands

**Start Development Server**
```bash
npx expo start
```

**Run on iOS Simulator**
```bash
npx expo run:ios
```

**Run on Android Emulator**
```bash
npx expo run:android
```

**Clear Cache**
```bash
npx expo start --clear
```

## Building for Production

### 1. Version Management
Update version in `app.json`:
```json
{
  "expo": {
    "version": "1.21.X"
  }
}
```

### 2. iOS Build Process

**Prebuild iOS Project**
```bash
npx expo prebuild -p ios
```

**Install iOS Dependencies**
```bash
cd ios && pod install && cd ..
```

**Open Xcode Workspace**
```bash
open ios/ALI2025.xcworkspace
```

**In Xcode:**
1. Configure signing in "Signing & Capabilities" tab
2. Select "Any iOS Device" from device selector
3. Product > Archive
4. Distribute App > Select distribution method

### 3. Android Build Process

**Prebuild Android Project**
```bash
npx expo prebuild -p android
```

**Build APK**
```bash
cd android && ./gradlew assembleRelease && cd ..
```

### 4. EAS Build (Cloud Building)

**Build for iOS**
```bash
eas build --platform ios
```

**Build for Android**
```bash
eas build --platform android
```

**Build for Both Platforms**
```bash
eas build --platform all
```

## Testing Workflow

### 1. Local Testing
- Test AR functionality on physical device (AR requires real device)
- Test camera permissions and functionality
- Verify navigation between all app sections
- Test 3D model loading and gestures

### 2. Key Features to Test
- **AR Screen**: 3D model rendering, pinch-to-zoom, rotation, double-tap reset
- **Camera Integration**: Vision camera functionality
- **Navigation**: All tab and stack navigation flows
- **Data Persistence**: AsyncStorage functionality
- **API Calls**: Axios HTTP requests

## Troubleshooting

### Common Issues

**Build Errors**
- Ensure all dependencies are installed: `npm install`
- Clear cache: `npx expo start --clear`
- Reinstall pods: `cd ios && pod install && cd ..`

**AR Issues**
- ViroReact requires physical device for testing
- Check camera permissions in device settings
- Verify AR capabilities on target device

**Version Conflicts**
- Update CFBundleShortVersionString in Info.plist
- Increment version in app.json
- Clean build folders if needed

**dSYM Warnings (iOS)**
- Missing debug symbols for ViroKit.framework and hermes.framework
- These are non-blocking warnings that don't affect app distribution

## Development Best Practices

### 1. Code Organization
- Keep components modular and reusable
- Use TypeScript for type safety
- Follow Expo Router conventions for navigation

### 2. AR Development
- Test AR features on physical devices only
- Implement smooth gesture controls (reference ViroARScreen improvements)
- Handle AR session lifecycle properly

### 3. Performance
- Optimize 3D models for mobile devices
- Implement proper loading states
- Use AsyncStorage efficiently for data persistence

### 4. User Experience
- Implement proper error handling
- Provide loading indicators
- Ensure smooth navigation transitions
